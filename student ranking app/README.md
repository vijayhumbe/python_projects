🎓 Student Ranking Web App

A web application that calculates student percentage, grade, and rank based on marks.
Built to automate academic result evaluation in a simple interactive interface.

🚀 Features

📊 Calculate percentage from student marks

🏆 Generate student ranking based on performance

🧮 Automatic grade assignment

🧑‍💻 Interactive UI built with Streamlit

⚡ Real-time result display

🛠️ Tech Stack

Programming Language: Python

Framework: Streamlit

📥 Installation & Setup
1. Clone the repository
git clone https://github.com/your-username/student-ranking-app.git

2. Navigate to the project folder
cd student-ranking-app

3. Install Streamlit
pip install streamlit

4. Run the app
streamlit run app.py
