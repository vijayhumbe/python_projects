# 🧮 Streamlit Calculator App

A simple interactive calculator built using Python and Streamlit.  
It performs basic arithmetic operations through a clean web interface.

---

## 🚀 Features
- Add, subtract, multiply, divide, and modulus operations  
- Interactive number input fields  
- Error handling for division by zero  
- Web-based UI using Streamlit  
- Instant result display with buttons  

---

## 🛠️ Technologies Used
- Python 3.x  
- Streamlit
